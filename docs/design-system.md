# Illustrated botanical direction

The supplied UI reference informs thick, rounded paper shapes, pear green, butter yellow, turquoise, and small coral accents. Original SVG doodles and a locally bundled rounded font replace the former fine-line editorial treatment. Tool controls appear only when needed; numerical water/light/comfort feedback stays visible beside each plant.

The miniature uses a smaller cyan-edged glass jar, a continuous warm faceted soil body, an uneven raised rear, restrained rocks/wood and three close planting positions. Plant identity comes from silhouette and attachment: low moss cushions, thick succulent rosettes, medium broad veined Fittonia and taller pinnate fern fronds. Health colors and droop remain driven by state.

Each effect has one owner: the water footprint and droplets use the chosen world target; terrain colors use moisture samples; the fixture and cone share a lamp frame; UI and comfort use the same model state. Studio lighting preserves a bright illustration while the practical spotlight changes the chosen area. Neither rendering brightness nor decorative glass highlights determine ecology values.

No external 3D models or generated raster assets are used. Reference pictures are not embedded as textures. Existing DM Sans and new Fredoka fonts retain their included OFL notices.
